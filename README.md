# AI-SYS-Learning-Note

> 聚焦 AI 系统中**算法层面的核心难点与优化方案**，兼顾系统设计与生产落地。

本项目以**算法视角**切入 AI native 系统（AI Systems / ML Systems），关注从算法原理到工程实现的完整链路。核心主题如下：

## 核心聚焦：算法层面的核心难点与优化

-  **Agent相关算法**
  - **Memory**: 如何设计一个好的记忆系统，如何存储-管理-检索
- **模型与服务算法**
  - 量化与压缩：INT8 / INT4 / FP8 量化、GPTQ / AWQ、稀疏化
  - 蒸馏与推理时增强：知识蒸馏、MoE 路由、推测式 / 多路径推理

## 支撑主题

- **系统设计**：AI 系统整体架构、组件划分与数据流设计
- **生产部署**：服务化、弹性扩缩容、可观测性与运维实践
- **性能调优**：吞吐 / 延迟 / 资源利用率的指标权衡与压测方法
